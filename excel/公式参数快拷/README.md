# 公式参数快拷

选中 Excel 公式，自动提取括号内的参数，批量生成同参数的不同函数公式。

**场景**：A1 是 `=AVERAGE(O393:O401)`，想让 A2、A3、A4 变成 `=MEDIAN(O393:O401)`、`=MIN(...)`、`=MAX(...)`——选中 A1 运行本宏即可。支持选区批量处理（如选中 A1:C1，分别在 A2:A4、B2:B4、C2:C4 生成）。

## ✨ 功能

- 单格 / 选区批量处理：选区内每个含公式的单元格分别提取参数、分别生成；
- 自定义函数列表：默认 MEDIAN, MIN, MAX，可改成任意函数（英文逗号分隔）；
- 四方向生成：下 / 右 / 左 / 上；
- 跳过无公式、无括号的单元格。

## 🚀 安装（macOS + Excel）

**方式一：一键安装器（推荐）**

用 macOS 自带的「脚本编辑器」打开 `installer.applescript`，另存为「应用程序」格式，把 `公式参数快拷.bas` 放进生成的 `.app/Contents/Resources/` 里，双击 `.app` 即可自动完成：打开 Excel → 打开宏编辑器 → 插入模块 → 粘贴代码。

首次运行如被 macOS 拦截：系统设置 → 隐私与安全性 → 辅助功能，给安装器打勾后重试。

**方式二：手动安装**

1. Excel 菜单「工具 → 宏 → Visual Basic 编辑器」（`Option + F11`）；
2. 「插入 → 模块」，打开 `公式参数快拷.bas`，**从第 2 行 `Option Explicit` 开始**粘贴（第 1 行 `Attribute VB_Name=...` 是 .bas 文件标记，粘进编辑器会报语法错误）；
3. `Cmd + S` 保存。

## 🎮 使用

1. 选中一个或多个含公式的单元格（只框源公式，别框要生成的目标区域）；
2. `Option + F8` → 运行「公式参数快拷」；
3. 确认 / 修改函数列表 → 输入生成方向（下 / 右 / 左 / 上）→ 确定；
4. 公式自动填入，弹窗报告处理了多少个单元格。

## 🌐 网页版

`web/index.html` 是纯网页工具，浏览器直接打开：粘贴多条公式 → 勾选函数 → 复制整列 → 到 Excel 里一键粘贴。适合一次性大批量组合、或多行公式分别处理的场景。

## 📝 备注

- 宏只新增公式，不改动已有单元格，`Cmd + Z` 可撤销；
- 生成方向是「相对每个源单元格」的，横向表格选「右」即可。
