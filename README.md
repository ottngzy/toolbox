# toolbox · 小工具合集

个人小工具仓库，按类别分文件夹存放。每个工具一个独立目录，内含源码、安装器和使用说明。

## 📂 工具目录

### Excel

| 工具 | 说明 | 目录 |
| --- | --- | --- |
| 公式参数快拷 | 选中 Excel 公式，批量提取括号内参数，按指定方向一键生成 MEDIAN / MIN / MAX 等同参数公式；支持一键安装到 Excel | [excel/公式参数快拷](excel/公式参数快拷) |

## 🗂 目录结构

```
toolbox/
└── excel/
    └── 公式参数快拷/
        ├── README.md            使用说明
        ├── 公式参数快拷.bas      VBA 宏源码（批量处理版）
        ├── installer.applescript macOS 一键安装器源码
        ├── 一键部署到Excel.command 终端版一键安装器
        └── web/
            └── index.html        网页版工具（多行公式批量组合）
```

## ➕ 新增工具

1. 在对应类别下新建目录（没有合适的类别就新建一个，如 `pdf/`、`mac/`）；
2. 目录里放一个 `README.md` 写清楚：是什么、怎么用、怎么安装；
3. 更新本文件的「工具目录」表格。
